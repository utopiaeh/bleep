# Store listing copy

Paste-ready text for the Chrome Web Store and Firefox Add-ons (AMO)
dashboards. The extension name and short description come from
`public/_locales/*/messages.json`; this file holds what the dashboards ask for
separately.

- **Summary** — AMO "Summary" (max 250 chars). Chrome uses the manifest
  description, so no extra field there.
- **Description** — Chrome "Description" / AMO "Description". AMO supports
  basic markdown; Chrome is plain text (the `•` bullets render fine in both).
- **Search terms worth keeping**: clear cache for this site, clear cookies
  for one site, clear site data, hard reload, service workers, localStorage,
  IndexedDB, developer cache cleaner.

## English (en)

**Summary**

Clear cache, cookies, storage and service workers for just the site you're on
— or everything at once. Protected sites, keyboard shortcut, no data
collected.

**Description**

Clear browsing data for one site without logging out of everything else.

Most cleaners wipe your whole browser. Bleep lets you clear just the site in
your current tab — perfect for fixing a broken page, testing a fresh load, or
getting rid of stale cache while staying signed in everywhere else.

• Clear this site only — cache, cookies, Local/Session Storage, IndexedDB,
Cache Storage and service workers for the current tab's site.
• Or clear everything — globally, across every site, including history,
downloads and form data.
• Keyboard shortcut — set your own key (Settings → Shortcuts) to clear the
current site without opening the popup.
• Hard reload — the tab reloads with fresh files right after clearing.
• Protected sites — sites you never want cleared (your bank, email…) are
skipped automatically.
• Origin mappings — also clear a linked login/SSO domain so apps can't
silently sign you back in.
• Pick exactly what to clear — separate checklists for global and per-site.
• Clear log, settings backup/restore, light/dark theme.
• English, Russian, Romanian and Ukrainian.

Built for web developers, QA and anyone who just wants a site to work again.

Privacy: Bleep collects nothing. No analytics, no tracking, no remote code —
everything happens locally in your browser. Access to sites is optional and
only requested the first time you clear a single site. Open source:
https://github.com/utopiaeh/bleep

• Только этот сайт — кэш, cookie, Local/Session Storage, IndexedDB, Cache
Storage и сервис-воркеры сайта из текущей вкладки.

• Сочетание клавиш — назначьте свои клавиши (Настройки → Клавиши), чтобы

• Жёсткое обновление — вкладка сразу перезагружается со свежими файлами.

• Английский, русский, румынский и украинский языки.

Для веб-разработчиков, тестировщиков и всех, кому нужно, чтобы сайт снова
заработал.

Приватность: Bleep ничего не собирает. Никакой аналитики, отслеживания и
удалённого кода — всё происходит локально в браузере. Доступ к сайтам
необязателен и запрашивается только при первой очистке отдельного сайта.
Открытый исходный код: https://github.com/utopiaeh/bleep

Majoritatea instrumentelor șterg tot browserul. Bleep curăță doar site-ul din
fila curentă — ideal pentru a repara o pagină stricată, a testa o încărcare
curată sau a scăpa de cache-ul vechi, rămânând conectat în rest.

• Doar acest site — cache, cookie-uri, Local/Session Storage, IndexedDB,
Cache Storage și service worker-ii site-ului din fila curentă.
• Sau totul — global, pe toate site-urile, inclusiv istoric, descărcări și
date din formulare.
• Comandă rapidă — setează-ți propria tastă (Setări → Comenzi rapide) pentru
a curăța site-ul curent fără a deschide popup-ul.
• Reîncărcare forțată — fila se reîncarcă imediat cu fișiere noi.
• Site-uri protejate — site-urile pe care nu vrei să le cureți (banca,
emailul…) sunt sărite automat.
• Corespondențe de origini — curăță și domeniul de autentificare/SSO asociat,
ca aplicația să nu te reconecteze pe ascuns.
• Alegi exact ce se curăță — liste separate pentru global și per site.

Pentru dezvoltatori web, QA și oricine vrea ca un site să meargă din nou.

Confidențialitate: Bleep nu colectează nimic. Fără analiză, urmărire sau cod
la distanță — totul rulează local în browser. Accesul la site-uri este
opțional și se cere doar la prima curățare a unui singur site. Cod sursă
deschis: https://github.com/utopiaeh/bleep
